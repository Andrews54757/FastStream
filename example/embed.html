FastStream embed API

The web build of FastStream can be embedded in an iframe and driven by the page that embeds it. The page and the player are on different origins, so everything goes over postMessage. This page is a working example of the whole protocol: it waits for the player to announce itself, subscribes to its events, and sends it commands.

        Protocol reference

        

            Commands are {type: 'faststream:command', id, command, args}, posted to the iframe's window.
            Every command is answered with {type: 'faststream:response', id, ok, result}, or
            {type: 'faststream:response', id, ok: false, error: {message}} when it failed. The
            id is whatever you labelled the command with, handed back so you can match the two up.
        

        

            Events are {type: 'faststream:event', event, state, detail}, where state is the
            same snapshot getState returns. They are only sent to windows that asked for them with
            subscribe. The exception is ready, which the player sends to whoever embedded it
            as soon as it has loaded — wait for it before sending anything, because an iframe's load event fires
            before the player's scripts have run.

                The chapters marked on the timeline
            

            

                load
                {url, mode, headers, subtitles, chapters, autoPlay, time}
                Plays a video, replacing whatever was playing
            

            

                addSource
                {url, mode, headers, setSource}
                Offers a video in the player's source list
            

            

                play, pause, togglePlay
                
                A play the browser blocks comes back as an error
            

            

                seek
                {time} or {delta}
                Moves the playhead, in seconds
            

            

                setVolume, setMuted
                {volume} 0–3, {muted}
                Above 1 amplifies, where the browser can

                {rate}
                
            

            

                setVideoLevel, setAudioLevel
                {id} from getLevels
                
            

            

                setLanguage
                {type: 'video'|'audio', language}
                
            

            

                addSubtitles
                {label, language, data|url, activate}
                WebVTT, SRT or TTML, as text or as a url the player fetches
            

            

                setSubtitleTrack, clearSubtitles
                {index, active}
                
            

            

                setChapters
                {chapters}, each {name, startTime, endTime}
                Marks chapters on the timeline; an end that is left out runs to the next chapter. They belong to
                    the video that is playing, so send them after (or with) the load
            

            

                setFullscreen, setPictureInPicture
                {fullscreen}, {pictureInPicture}
                Needs the iframe's allow attribute, and a user gesture
            

            

                subscribe, unsubscribe
                {events}, or nothing for all of them
                Events are sent to the window that subscribed, at its own origin
